What is JSX -
    Javascript XML - it helps you write HTML in Javascript .
    JSX converts Html tags into react elements
        eg - const myElement = <h1>I Love JSX!</h1>
        with JSX we can write expressions inside curly braces{} , expressions can be js variable, property , function call 
            
            eg- const myElement = <h1> Using jsx expresstion its a {10} </h1> 
            eg- function Car() {
                const mystyles = {
                    color: "red",
                    fontSize: "20px",
                    backgroundColor: "lightyellow",
                };

                return (
                    <>
                    <h1 style={mystyles}>My car</h1>
                    </>
                );
                }

        -> The html code must be wrapped in One top level element , so put them in div or a fragment (<> </>)
        -> user attribute classname instead of class in jsx 
        -> Comments in jsx {/*  */}
        
        -> React support if statement but not inside jsx , we can write them outside jsx 
        

React render Html  -
    : React create html elements inside a defined container ( root container inside index.html file)
    - index.js 

        createRoot(document.getElementById('root')).render(
        <StrictMode>
            <App />
            </StrictMode>
        )  

        createRoot() : takes 1 arg that is the html element . In this container the html component will be displayed 

        render(): method defines what to display in the html container 

React Components 
    : components are independent and reusable piece of code . Work in isolatino and return HTML elements 
        Two types - function component 
                  - class component 

    Function Components
        : creating a react component we must start the name with Capital Letter , return HTML code 
        eg- eg function Cars(props){
                return(
                    <h2> Rendering HTML <h2/>

                )
            }
        -> Rendering a Component 
            eg - createRoot(document.getElementById("root").render( <Cars />))

            *React Props :
                Arguments can be passedd into a components as props(properties) 
                eg - createRoot(document.getElementById("root").render( <Cars  color="red "/>))
                Props are passed to components via HTML attributes 
                    eg- function Cars(props){
                        return(
                            <h2> Cars looking like {props.brand} <h2/>

                        )}
                        createRoot(document.getElementById("root")
                        .render
                        ( <Cars  brand= "bmw" />))
                    
                    Multiple Props-
                        ( <Cars  brand= "bmw"  color="black"  model="m5"/>) 

                * Destructing Props
                    -to limit the properties inside the component.
                    eg - function Car(props) {

                    }

Reacts Hooks 
    : Hooks allows functino to have access to state and other React features without using classes. They provide directs API to React Concepts like props , state etc .
    - Hooks are functions that let you "hook into" React state and lifecycle features from functional components.  Must import the HOOK before use

    # useState :
    It allows us  to track state in a function component
    State generally refers to data or Properties that need to be tracking in an application 
        -> Initialize useState by calling the useState function inside the function components 
        const [color , setcolor] = useState("red") 
        here color - the current  state (red) ; 
             setcolor - a function that updates the state ;

        The useState Hook can be used to keep track of strings, numbers, booleans, arrays, objects, and any combination of these!
